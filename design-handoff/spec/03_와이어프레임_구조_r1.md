## 1. S-01 시작

```text
┌──────────────────────────────────────────────────────┐
│  일단확인                                            │
│                                                      │
│  근로조건, 어떤 기준으로 확인해야 할지 모르겠다면?  │
│  AI가 찾아주고, 기준으로 점검하고, 원문으로 확인해요. │
│                                                      │
│  [ 문서 확인하기 ]                                    │
│                                                      │
│  채용공고 · 오퍼 안내 · 근로계약서                    │
│  10개 근로조건 주제 | 법령·공식서식·서비스 기준 구분 │
│                                                      │
│  ※ 문서의 기재 상태를 정리하며 법적 적합성은 판단 X │
└──────────────────────────────────────────────────────┘
```

- '정부 인증' '법적 문제 없는 계약' 같은 보증 문구 금지.
- 10개는 **점검 주제의 총 개수**. 특정 문서의 결과 목록은 9개 또는 10개.


**S-03**: 추출 결과를 편집 가능하게 표시하고, 원본과 숫자·날짜·시간을 비교하도록 안내. 사용자의 확인 없이 자동 분석하지 않음.

**S-04**: 진행 상태와 중복 분석 방지. 실패 시 원문 보존. '법률 위반 검사 중' 같은 오해 표현 금지.

## 3. S-05 점검 결과 — 기본 상태

예시: 수습 적용이 확인되어 10개 표시, 연봉은 기재되었으나 일부 D 정보가 없음.

```text
┌──────────────────────────────────────────────────────┐
│  ← 뒤로       일단확인                               │
│                                                      │
│  오퍼 안내문을 확인했어요.                            │
│  점검한 항목 10개                                    │
│  각 항목의 상태는 '문서에 적힌 정보'를 뜻해요.        │
│                                                      │
│  ──── 주요 항목 ───────────────────────────────────  │
│  01 임금             [ 주요 내용 기재됨 ]       ›    │
│     연봉 금액·단위 확인. 지급방법은 별도 확인 필요   │
│  02 근무시간         [ 일부 내용만 기재됨 ]     ›    │
│     출퇴근 시각은 있으나 휴게시간은 불분명           │
│  03 근무장소         [ 일부 내용만 기재됨 ]     ›    │
│     서울 소재. 구체 장소는 확인되지 않음             │
│  04 담당업무         [ 주요 내용 기재됨 ]       ›    │
│  05 고용형태         [ 주요 내용 기재됨 ]       ›    │
│  06 계약기간         [ 관련 내용 찾지 못함 ]     ›    │
│  07 수습기간         [ 주요 내용 기재됨 ]       ›    │
│  08 수습 중 급여     [ 일부 내용만 기재됨 ]     ›    │
│  09 휴일             [ 관련 내용 찾지 못함 ]     ›    │
│  10 연차 유급휴가    [ 일부 내용만 기재됨 ]     ›    │
│                                                      │
│  ※ 입력한 문서 기준의 정보 확인이며 법률 판단 X     │
│  [ 다른 문서 확인하기 ]                              │
└──────────────────────────────────────────────────────┘
```

- 상위 4개 라벨을 고정해서 사용. `분명하지 않음` 등 **구형 상위 라벨 병용 금지**.
- **08 숨김**: 목록에서 제거, 상태 미생성, **06 등 나머지 9개 주제는 표시**, 헤더 `점검한 항목 9개`. 07 상세의 안내에서 '수습 적용 여부가 확인되지 않아 08은 별도 판정하지 않음' 설명.
- 09·10은 단순 참고 영역이 아니라 정식 항목이다. 문서에 근거가 없다면 별도 상태를 계산.
- **채용공고의 M 상태 표시**는 D01 미결정. 현 시안은 전 항목 판정 후 M 목록을 기본 접기(펼칠 수 있게) 제안. **접혀도 판정은 존재하며 `점검한 항목 N개`에 포함**한다. 승인 전 확정안 아님.
- 상세에 누락 D가 있어도 상위 F로 남을 수 있으므로 '모든 기준 충족' 같은 문구 금지.
- 상태 색은 무채색과 주석 스타일로 표현. `MAIN_FOUND`에 초록 체크·합격 스탬프 금지.

## 4. S-06 항목 상세 — 임금 예시

입력 예시: `연봉 4,000만원 (기본급 및 고정수당 포함)`.

```text
┌─────────────────────────────────────────────────────────┐
│ ← 점검 결과                                             │
│ 01 임금                                                │
│ [ 주요 내용 기재됨 ]                                   │
│ 연봉 금액과 산정 단위가 문서에서 확인됩니다.             │
│ ※ 다른 세부 내용의 확인 여부와는 별개입니다.            │
│                                                         │
│ ── 문서 원문 ────────────────────────────────────────── │
│  “연봉 4,000만원 (기본급 및 고정수당 포함)”               │
│   원문 3번째 줄                                         │
│                                                         │
│ ── 세부 확인 기준 ───────────────────────────────────── │
│  핵심(C)                                                │
│  01-a 금액/산정값          [ 확인됨 ] 4,000만원           │
│  01-b 산정 단위           [ 확인됨 ] 연봉                 │
│                                                         │
│  추가(D)                                                │
│  01-c 구성항목           [ 일부 확인 ] 기본급·수당 포함  │
│  01-d 계산방법           [ 확인되지 않음 ]                │
│  01-e 지급방법           [ 확인되지 않음 ]                │
│  01-f 지급일             [ 확인되지 않음 ]                │
│  01-g 세전·세후          [ 확인되지 않음 ]                │
│                                                         │
│ ── 기준의 출처 ──────────────────────────────────────── │
│ [L-M] [L-W] [F] [S] (개별 기준별 출처 링크)             │
│ 서면명시·교부 규정이 적용되는지는 판단하지 않아요.        │
│                                                         │
│ ── 이 문서에서 확인되지 않은 내용 ──────────────────── │
│ 구성항목별 금액, 계산방법, 지급방법, 지급일 ...          │
│                                                         │
│ [ 원문 수정하고 다시 분석 ]   [ 결과 목록 ]              │
└─────────────────────────────────────────────────────────┘
```

**표시 정책**
- 세부기준은 ID순으로 나열하고 **C를 먼저** 보여준다. 설명은 상태값과 별도의 문장.
- `PARTIAL`(원문에 일부 사실 존재)과 `UNCLEAR`(값 자체 미정/충돌)를 구분.
- '지급일'은 공식 서식 참고 F이며 근로기준법 제17조의 직접 서면명시 항목이라고 오기하지 않는다.
- 선택한 세부기준에만 근거 원문이 있을 수 있음. `MISSING`에 가짜 인용 카드를 표시하지 않음.

## 5. S-06 예외 화면들

### 5-1. 수습 미정 — 08 숨김

```text
07 수습기간 [ 일부 내용만 기재됨 ]
원문: “수습 여부는 최종 면담 후 결정합니다.”
07-a 적용 여부  [ 불분명함 ]
07-b 수습기간   [ 확인되지 않음 ]

수습 적용 여부가 확인되지 않아
'수습 중 급여'는 별도로 판정하지 않았습니다.
수습이 적용된다면 해당 급여 조건도 확인할 수 있습니다.
```

### 5-2. 연차 미부여 — 결과 승인처럼 표현 금지

```text
10 연차 유급휴가 [ 주요 내용 기재됨 ]
기재 사실: “연차 없음”
10-a 부여 여부  [ 확인됨 ]  문서상 미부여로 기재됨
10-b 부여 기준  [ 해당 없음 ]  문서상 미부여 분기

[중립 안내] 문서에 적힌 내용만 확인했습니다.
법적 효력이나 실제 적용 여부를 판단한 결과가 아닙니다.
[적용 범위 안내] 법령 적용 여부는 사업장 규모·근로시간 등
실제 사정에 따라 달라질 수 있으며, 일단확인은 판단하지 않습니다.
```

- '해당 없음'은 서비스 세부기준의 조건부 미적용에만 사용. 사용자 본인의 법률 적용 제외를 뜻하지 않는다.

### 5-3. OCR 핵심값 저신뢰

```text
03 근무장소 [ 분석 확인 불가 ]
신뢰 가능한 부분: “종로구 세종대로 …”
주소 중 일부가 불확실하게 읽혔습니다.
원본 이미지에서 주소를 확인해 텍스트를 수정해 주세요.
[ 원문 다시 확인 ]
```

`PARTIAL`(회사 문서에 덜 적힘)과 `UNAVAILABLE`(분석이 제대로 읽지 못함)의 의미를 혼동하지 않는다.

### 5-4. 계산값

```text
02 근무시간 [ 주요 내용 기재됨 ]
원문: “월~금 09:00~18:00, 휴게 12:00~13:00”
원문에서 계산한 값: 하루 8시간, 주 40시간
계산 근거: (18:00-09:00)-(13:00-12:00)=8시간
```

계산값에 '원문에 적혀 있음' 표현 금지. 격주·교대는 별도 스키마 D03 결정까지 단일 고정시간/평균으로 대체하지 않는다.

## 6. S-07 오류·재시도

```text
[ 분석 확인 불가 ]
이 항목의 원문 근거를 안전하게 확인하지 못했습니다.
입력 문서를 다시 확인하거나 분석을 재시도할 수 있습니다.
[ 원문 수정 ] [ 다시 분석 ]
```

- 근거 검증 실패 한 항목 때문에 이미 검증된 나머지 항목을 자동 삭제하지 않는 설계.
- OCR D만 오류면 해당 D만 U. 핵심(C)이 불확실하면 해당 상위 U.
- '미기재'로 변환 금지.

## 7. 화면 카피·배지 규칙

| 사용하지 않을 문구 | 권장 문구·원칙 |
|---|---|
| 법적으로 문제없음 | 문서에서 주요 내용 기재됨 |
| 근로계약서 합격/위험 | 기재 상태를 확인했어요 |
| AI가 정확히 판단했어요 | AI 분석을 바탕으로 원문 근거를 확인했어요 |
| 추가로 확인해 보세요 (질문 요구처럼 보일 수 있음) | **이 문서에서 확인되지 않은 내용** |
| 필수사항 전부 충족 | 해당 핵심 기준의 기재 여부 확인 |
| 10개 중 10개 완료 | 점검한 항목 N개 (N=실제 표시 수) |

## 9. 미결정 상태

| ID | 미결정 사항 | 현재 초안의 임시 처리 | 확정 전 주의 |
|---|---|---|---|
| D01 | 채용공고 `MAIN_MISSING` 목록 노출 방식 | M 판정을 유지하고 접을 수 있는 그룹으로 표시하는 시안 | 접힌 상태에서도 접근 가능해야 하며, 점검한 항목 N개에 포함 |
| D02 | 06 계약기간 상시 노출 정책 | 동결 기준표에 따라 06은 모든 문서에서 판정·표시하는 현 초안 유지 | 06 숨김으로 바꾸려면 기준표 버전과 9/10 집계 규칙을 함께 재검토 |
| D03 | 격주·교대 근무시간 계산값 형식 | 주별 원문 및 검증된 계산값을 보존하며 단일 평균·고정값으로 축약 금지 | 주기/주별 값 목록의 API·화면 형식 미정 |
| D04 | 휴게시간 미부여 표현의 `neutral_note` | 노출 여부 미확정, 해당 플래그의 정확도 채점 보류 | 변경할 경우 동결 기준표를 조용히 수정하지 않고 후속 버전에서 확정 |
