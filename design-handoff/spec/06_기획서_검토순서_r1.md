PRD의 가치·범위 → 기준표 4장(C/D) → 기능정의서 F05~F11 → 결과/상세 화면 → **미결정 D01~D06**.

## 정합성 보정 범위

- 기준표 `04_...`의 판정 로직과 SHA-256은 수정하지 않음. PRD/기능정의서/화면 설명만 맞춤.
- `D02`는 현 동결 기준의 06 상시 표시를 전제로 하는 **향후 변경 제안**이며, 임의로 06을 숨기지 않음.
- 06의 `기간 정함 없음`을 `MAIN_FOUND`로 분류하는 것과 `neutral_note` 표시 여부는 별도 규칙. 06에 중립 안내 자동 표시하지 않음.
- 채용공고의 접힌 M 그룹(D01)은 표시 수 N의 계산에서 빠지지 않음.
- 실제 검증·법률 검토의 완료 여부를 변경하지 않음.
- 상세 수정 목록은 `05_정합성_검토_변경로그.md` 참고.
