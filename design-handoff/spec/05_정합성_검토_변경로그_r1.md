## 3. 의도적으로 미확정인 사항

D01~D06은 모든 문서에서 같은 표로 유지한다. 특히 D03의 주별 값 데이터 형식, D04의 휴게 부정문 안내, D05의 모델 안정성, D06의 전문 검토는 **완료로 간주하지 않음**.

## 4. 검토 후에도 남은 한계

1. 원문 OCR 구간별 신뢰도를 기술적으로 가져올 수 있는지, 수정된 구간의 신뢰도 플래그를 어떻게 갱신할지는 별도 구현 설계·테스트 필요. 이번에 구현 확정하지 않음.
2. 기준표의 세부 `L-M/L-W/F/S` 연결은 제품의 법적 인증이 아님. 법 적용 범위·법령 최신성 검토(D06)가 남음.
3. 문서의 설계 정합성은 앱의 실행 정확도를 입증하지 않음. v2.2의 10개 판정은 실제 Gemini로 검증하지 않았음.
4. 실제 Figma 편집이나 GitHub 코드 수정은 수행하지 않았음.
