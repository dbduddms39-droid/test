## 구현 단계 제안 (계획 승인 후)

1. 공통 디자인 시스템: 오프화이트, 노란 하이라이트, 파란 교정선, Pretendard. 반응형 1440/900/390 및 접근성.
2. S-01~S-07 화면 흐름: S-01 랜딩 -> S-02 텍스트/사진/PDF 입력 -> (파일만) S-03 추출 결과 확인 및 수정 -> S-04 분석 중 -> S-05 결과 -> S-06 항목 상세; 전체 실패 시 S-07.
3. 문서 텍스트/유형·업로드 출처/수정사항을 결과·오류·재시도 사이에서 보존. 중복 분석 방지.
4. 동결 기준표의 10개 주제 및 세부 ID와 상태 로직 정확히 적용. **07 수습 적용이 확인될 때만 08 수습 급여를 표시**하며 보이는 항목 수는 9 또는 10.
5. 핵심 C/추가 D 분리 및 법령 출처 L-M/L-W/F/S; **화면에는 사람이 읽기 쉬운 한국어 라벨**을 사용하고 `01-a`, `C`, `D` 같은 내부 식별자는 데이터 속성 등 내부에 유지.
6. AI 추출 근거 원문을 최종 사용자 확인 텍스트와 문자 단위로 검증. 허위 인용·핵심 OCR 불신은 '찾지 못함'으로 처리 금지. 계산값과 인용 원문 구분.
7. 화면 연결/반응형/키보드 접근성/테스트. 임시 `#` 링크, 모의 버튼 동작, 가짜 진행률·검증 완료 표현 제거.

## P0에 포함하지 않는 것

- 근로계약서 전용 퇴직급여·사회보험 2개 추가 및 특약 분류: **P1 이후**.
- 법률 위반 판단, 계약 효력, 기업 평가, 두 문서 비교, 회원가입/보관함/알림.
- 모델 정확도 검증 완료 주장: 실제 Gemini 검증은 별도 과제이며 완료된 것으로 표시하지 마세요.

## 반드시 지킬 제품 원칙

- 서비스는 **문서에 적힌 정보의 기재 상태**를 확인합니다. 법적 적합성을 평가하지 않습니다.
- 상위: 주요 내용 기재됨 / 일부 내용만 기재됨 / 관련 내용 찾지 못함 / 분석 확인 불가.
- 세부: 확인됨 / 일부 확인 / 불분명함 / 확인되지 않음 / 해당 없음 / 분석 확인 불가.
- 세부 D 누락은 C로 결정한 상위 상태를 낮추지 않습니다.
- '연차 없음' 등 명시적 부정의 **기재 사실 확인**을 법적 승인처럼 표현하지 않습니다.
- '보안 모드', 영구 데이터 저장, 분석 완료율/정확도 등 검증되지 않은 표현을 넣지 않습니다.
