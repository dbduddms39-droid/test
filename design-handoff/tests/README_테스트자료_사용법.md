# 일단확인 · 테스트 자료 보충 인계

이 폴더는 기존 개발 인계 ZIP에서 빠졌던 **기획상 테스트 자료**를 보충합니다. 실제 Gemini 실행 결과나 모델 정확도 인증이 아닙니다.

## 파일 매핑

- `ildan_check_fixtures_expectations_v2.1.md`: F01~F05 가상 문서·상위 기대 판정·경계 사례(동결 v2.2에서도 해당 50칸의 상위 기대값 보존)
- `ildan_check_fixtures_blind_v2.2.md`: F06~F08 가상 문서 원문
- `ildan_check_new_expectations_v2.2.md`: F06~F08 당시 기대 판정표 (아래 정정 주의)
- `ildan_generalization_fixtures_F09-F11_blind.md`: F09~F11 가상 문서 원문
- `01_oracle_preregistration_v2.2.1.md`: F09~F11 상위 기대값, 세부 기대 보완, 미결정 경계 안내
- `ildan_F09-F11_oracle_vs_blind_report.md`: F09~F11 사람의 블라인드 평가 비교 기록 및 미확정 항목

## 우선순위와 주의 사항

1. **기준의 단일 원천은 기존 인계 패키지의 v2.2 동결 기준표**입니다. 파일이 충돌하면 테스트 자료에 맞춰 기준을 바꾸지 말고 충돌을 보고합니다.
2. F06~F08의 기존 기대표 `ildan_check_new_expectations_v2.2.md`에는 F06 '법정 기준 이상 부여'에 대해 `10-a PARTIAL`로 적힌 **동결 전 기대값**이 있습니다. **동결 v2.2의 정정된 기준은 `10-a CONFIRMED`, `10-b MISSING`, 상위 `MAIN_PARTIAL`**입니다. 테스트 만들 때 동결 기준이 우선입니다.
3. F09~F11은 v2.2.1 사전등록 보완문서와 블라인드 보고서가 일부 다르게 적힌 *경계 사례*를 포함합니다. F09의 임금 지급방법(01-e), 연차 기준(10-b)은 보완 판정 `PARTIAL`을 우선하되 원래 판정과 차이를 기록합니다.
4. F09/F10의 **휴게 부정형 `neutral_note`**는 결론이 동결되지 않았으므로 테스트의 정답/오답 채점에서 제외하고 진단으로만 기록합니다.
5. F09의 격주 근무시간은 주 40시간과 43시간을 각각 보존해야 하며 단일 평균이나 항상 동일한 값으로 표시하지 않습니다. 시간별 표현 스키마는 미결정 D03입니다.
6. F09~F11 보충 오라클에 없는 세부 항목은 임의로 확정 정답을 만들지 않습니다.
7. OCR 관련 픽스처의 저신뢰 플래그는 테스트에서 명시적으로 입력되어야 합니다. 근거 없는 자동 OCR 신뢰도 세그먼트 판정을 주장하면 안 됩니다.

- **실제 AI 정확도와 법률 타당성은 이 파일들이 검증한 결과가 아닙니다.**
