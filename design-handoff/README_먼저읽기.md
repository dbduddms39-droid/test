# 일단확인 — Claude Code 개발 인계 패키지

## 사용법

이 폴더는 **기존 일단확인 React 웹앱 저장소**에 참고자료로만 추가하세요. 기존 `src`나 앱 구성 파일을 덮어쓰지 마세요.

예시: 저장소 루트에 `design-handoff/` 폴더를 만들고 이 ZIP의 내용을 그 안에 풀어 넣습니다.
Claude Code에서 저장소를 연 뒤 `design-handoff/CLAUDE_CODE_작업지시.md`를 읽고 그대로 작업하도록 요청하세요.

## 인계된 파일

- `design/S-01_landing` ~ `design/S-07_error_retry`: 최종 스티치 화면별 `code.html`, `screen.png`, `DESIGN.md`
- `spec/01_PRD_latest_r2.md`: 최신 제품 범위 결정 (P0 10개, P1 계약서 확장 제외)
- `spec/02_기능정의서_r1.md`: 기능과 상태 명세
- `spec/03_와이어프레임_구조_r1.md`: 7개 화면 이동 흐름
- `spec/04_점검기준표_v2.2_동결원문.md`: 판정 규칙의 **최우선 단일 기준** (SHA-256 `666e0fc1bd87cb2a5e0bff492f736b98d774fb5a29d8fc5398554ec131f1228a`)
- `spec/05_정합성_검토_변경로그_r1.md`: 정합성 변경 내용
- `spec/06_기획서_검토순서_r1.md`: 문서 관련 주의

## 읽기 우선순위 및 충돌 해결

- **판정 규칙/예외/ID**: v2.2 동결 기준표가 최우선. 수정·추측 금지.
- **제품 P0/P1 범위**: 최신 PRD r2가 최우선.
- **기능·화면 흐름**: 기능정의서·와이어프레임은 위 두 문서와 일치하도록 구현.
- **시각 디자인**: 스티치 시안 참조. 스티치 HTML은 독립적인 데모이며 실제 앱 코드를 대체하지 않음.

## 주의

스티치 HTML의 Tailwind CDN, 외부 아이콘 폰트, 가짜 링크·버튼, 더미 텍스트·모션은 실제 제품 구현의 증거가 아닙니다. 스크린샷을 시각 기준으로 삼되 기능은 기존 코드와 기획 명세에 따라 구현하세요.

일부 디자인 미결정(D01~D06)은 기존 결정 상태대로 유지합니다. 시각적으로 필요한 세부사항을 임의로 새 정책으로 확정하지 마세요.

문서 입력 텍스트가 서버와 AI로 전달될 수 있다는 개인정보 안내를 유지하고, 암호화·비저장 등 확인되지 않은 보장을 추가하지 마세요.
