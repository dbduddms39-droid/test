# 일단확인 — 확인 질문 QA 기록 (2026-10-12)

## 목적
사용자가 문서 두 개를 비교하거나 근로계약서 한 장을 확인했을 때, 회사에 물어볼 질문이 **불필요하게 많거나 누락되거나 문서 내용을 과장하는지** 검수한다.

이 기록의 테스트는 가상 원문과 사람이 지정한 추출 응답(시나리오/모의 AI)을 사용한다. **실제 Gemini 호출 성공, OCR 정확성, 법적 적합성 또는 사용자에게 질문이 유용한지는 증명하지 않는다.**

## 반영한 원칙
- 두 문서에서 값·단위가 명확하게 달라진 조건은 최종 적용 조건을 묻는다.
- 첫 문서에 없는 **핵심** 조건이 두 번째 문서에 새로 기재되면 적용 여부를 물을 수 있다.
- 단, 새로 기재된 조건이 '추후 협의/별도 협의' 등 미확정이라면 적용 여부보다 구체적인 지급/적용 기준을 묻는다.
- 처음 문서부터 미확정이었던 조건이 뒤 문서에는 없다면 '그대로 적용되는지'라고 묻지 않는다. 구체적으로 정해진 내용을 요청한다.
- 새로운 보조 정보(지급일·휴게시간 등)는 이미 명확히 기재됐다면 무조건 반복 질문하지 않는다.
- 근로계약서 한 장의 주요 조건이 기재됐더라도 지급방법·지급일·휴게시간처럼 선택된 세부 정보가 확인되지 않으면 질문한다.
- 동일한 조건, 분석 검증에 실패한 항목, 해당 없음은 회사의 미기재 문제라고 단정하지 않는다.
- 어떤 문구도 법률 위반이나 기업의 신뢰도를 판정하지 않는다.

## 자동 테스트 검증 범위
| 가상 시나리오 | 기대 결과 |
| --- | --- |
| 채용공고·계약서 연봉 값 불일치 | 최종 적용 금액 확인 질문 |
| 채용공고·오퍼 수습 급여 '별도 협의' 첫 등장 | 구체적인 수습 급여 기준 질문 |
| 오퍼·계약서, 앞 문서에 없고 뒤 문서에 '별도 협의'만 기재 | 구체적인 기준 질문 |
| 앞 문서 '추후 협의', 뒤 문서 미기재 | 조건 유지 단정 없이 현재 적용 기준 질문 |
| 앞 문서에 없는 수습 3개월이 뒤 문서에 명확히 기재 | 적용 여부 확인 질문 |
| 뒤 문서에 지급일만 새로 기재 | 별도의 반복 질문 없음 |
| 계약서 급여 기재됐지만 지급방법·지급일 없음 | 세부 정보 확인 질문 |
| 계약서 근무시간 기재됐지만 휴게시간 미확정 | 휴게시간 확인 질문 |
| 원문 분석 실패·인용 검증 불가 | 기재 누락으로 단정하는 질문 없음 |
| 동일한 조건 | 재확인 질문 없음 |

## 아직 검증되지 않은 부분
1. 실제 개인정보 없는 테스트 문서를 사용한 **Gemini 추출 정확도**와 **인용 줄 검증**의 성공률.
2. 질문 우선순위가 사용자에게 적절한지에 대한 구직자 검증. 자동 테스트는 템플릿의 정확한 출력만 확인한다.
3. 길이가 긴 문서, 복합 급여 구조, 서로 모순된 원문, 추출 실패 문서에서 질문이 중복·과다 생성되는 사례.
4. 수습 급여는 명시적으로 수습 적용이 확인된 문서에서만 나타나야 하며, OCR/AI 오류일 때는 정확성 재확인이 필요하다.

## 수정 파일
- `public/questions.js`: 핵심 조건과 구체성에 따른 질문 구분
- `test/questions.test.js`: 단위 회귀 시나리오 추가
- `test/compare.test.js`: 가상 채용공고→오퍼 분석과 실제 질문 생성 연결 테스트

## 품질 기준
테스트 통과를 서비스 품질이 검증된 것으로 홍보하지 않는다. 서비스는 **원문에 기재된 근로조건과 차이**를 보여주고 **확인 질문 초안을 제안**할 뿐, 법률 위반이나 실무 적용 결과를 확정하지 않는다.

## 수습 관련 질문 묶음 정책 (2026-10-12 추가 결정)
- 수습기간(07)과 수습 중 급여(08)에 대한 질문이 모두 생성될 때 **편집 가능한 질문 1개**로 묶는다.
- 각 항목의 비교 결과·분류 이유·원문 근거는 별도로 보여 준다. 질문을 합친다고 결과를 병합하지 않는다.
- 한쪽만 질문 대상이면 다른 항목은 억지로 포함하지 않는다.
- 두 문서 모두 수습 적용을 확인할 수 없고 수습 중 급여도 미기재되면 수습 급여만을 위한 질문을 생성하지 않는다.
- 수습 중 급여가 실제 문서에 별도로 기재된 경우에는 적용 여부가 불확실하더라도 문서 내용을 임의로 삭제하지 않는다.
- 결합 질문에서 두 조건의 원문 기반 확인 사유를 모두 남기고, 인사와 감사 인사는 각각 한 번만 표시한다.

### 추가 회귀 시나리오
- 수습기간 3개월과 급여 90%가 모두 뒤 문서에 처음 등장 → 질문 1개, 두 조건 모두 포함
- 급여 90%만 처음 등장, 수습기간은 동일 → 급여 질문만 유지
- 수습 적용과 수습 급여 모두 양쪽 미기재 → 수습 급여 질문 자동 생성하지 않음
- 계약서 단독에서 수습기간·수습 급여 모두 확인 필요 → 질문 1개
